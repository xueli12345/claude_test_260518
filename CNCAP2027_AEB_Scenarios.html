测试结束与有效性判定条件
单次试验结束条件
1. VVUT = 0 km/h 或 VVUT ≤ VTarget（纵向场景）
2. VUT 和目标物之间发生接触
3. 目标物离开 VUT 行驶路径
测试场景终止条件
1. VVUT ≤ 40 km/h：车速减少量 < 3 km/h
2. VVUT > 40 km/h：车速减少量 < 20 km/h
3. 拓展场景低速碰撞 → 停止高速试验
4. 误作用预测试中车辆对无碰撞风险目标产生紧急制动/避让
5. 厂商预测无性能时
试验有效性判定流程
无预估结果：每个试验点只开展一次试验。
有预估结果：按以下流程判定：
1. 第一次试验 → 与预估无差异 → 最终结果
2. 第一次有差异 → 第二次试验 → 与预估无差异 → 最终结果
3. 前两次有差异 → 第三次试验 → 取无差异的两项平均
4. 三次皆有差异 → 中止试验，分析原因后重试
5. 累计5次无效 → 不再使用预估结果
差异判定：速度差异 > 5 km/h 或报警时间与预估不同
